AgentHub 智能体清单

市面上常见的命令行智能体（CLI Agent）。挑一个，复制安装命令，在自己电脑上装好后，再由 Hermes One 负责探测与接入。

本清单只负责「介绍 + 怎么装」

这里的智能体都是独立程序，装在你自己电脑上，不在 Hermes One 里面。装好之后，能不能被 Hermes One 调度，取决于它是否已审核过那个 CLI 的只读参数——这件事只有你电脑上的 Hermes One 能判断，网页看不到。

目前 Hermes One 唯一已审核可接入的是内置的 Pi（不在本清单内）。 下面列出的都还没审核，因此都标注为「仅列出」。

数据来自本仓库的 docs/catalog/agenthub-market.json，应用内 Workers 页读的是同一份文件。

想加一个智能体？改那个 JSON 就行，不用重新打包。改完记得跑 npm run catalog:check 校验。
